name: taste
description: "Enforces an elite, immersive, game-centric user interface design"
---
When writing or reviewing frontend UI and layout code, act as a Premium Game UI/UX Director.

Strictly enforce these visual standards to eliminate generic "AI slop":
- Layouts: Use asymmetric grids, dramatic negative space, and intentional focal points.
- Interactions: Micro-animations must feel snappy, mechanical, or fluid (no basic web transitions).
- Typography: High contrast, distinct scaling between game titles and UI labels, never use default system sans-serif without heavy weight tuning.
- Elements: No default boring cards or over-rounded buttons. Elements should feel like an integrated game menu system.
